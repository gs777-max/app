# FIT LAB — Driver Total Fitting v3.0.1 (Head × Shaft × Grip)

絵を選ぶだけのドライバー総合フィッティング診断。単一ファイル `index.html` のみで動作します（Google Fonts と任意の Open-Meteo 無料気象APIのみ外部通信。オフラインでも全診断機能が動作します）。

## v3.0.1 での変更点（2026-11-21 — 結果画面の下部固定ナビの重なり修正）

- ステップ4（結果画面）の下部固定ナビ（`← 球筋と打点に戻る`／`最初からやり直す`）が、スクロール中に結果カードの下部に重なって見える問題を修正。
  - ナビの背景を半透明グラデーションから不透明の紙色に変更（カードの文字が透けなくなった）。
  - ステップ4の下部に 96px の余白を追加し、最後の結果カードがナビの上まで完全にスクロールできるようにした。
- エンジン・ギア・ゲート（1〜4位ロック）に変更なし。

## v3.0 での主な変更点（2026-11-21 — 2026年版グリップ最適選定エンジン＆因果ロジックツリー統合）

1. **グリップ選定の「ギアトータルランキング」完全マージ**
   - グリップ単独ランキングではなく、全候補（ヘッド14モデル × シャフト115本）の1組ごとに2026年版グリップ選定エンジン（5ステージ・2系統決定木・7メーカー19モデル）を実行。
   - 総合適合スコアを **ヘッド×シャフト（88%）＋ グリップ因果適合度（12%）** に統合し、ベスト10の各カード内に **最適グリップモデル・口径/BL・工房オーダー（左右下巻き枚数・巻き方）・外径増分・ΔSW・発火ルールID・NG除外理由・4段因果トレース解説** を一体化表示。
2. **2026年版グリップ選定アルゴリズム（5ステージ・2系統ロジックツリー）完全実装**
   - **ロジックツリーA（機構・重量・素材・BL）**：可変スリーブ時のBL無強制 `R-BL01`、シャフト重量・HS連動の目標重量帯 `R-WT01`（52〜55g）／`R-WT02`（49〜52g）、雨天・手汗・コード許容度による `R-MT01`（コード）／`R-MT02`（NK510シリカゴム・撥水樹脂自動切替）／`R-MT03`（SW繊細タッチ）。
   - **ロジックツリーB（テーパー・口径・左右巻数・巻き方）**：D-Plane逆算フェース角・短持ち頻度からの右手目標巻数 `R-TP01`（5〜6巻相当）／`R-TP02`（3〜4巻相当）／`R-TP03`（1〜2巻）、手サイズ・手元剛性 `R-LH01/02`、巻き方決定 `R-WM01`（全面らせん1巻）／`R-WM02`（ハイブリッド巻）／`R-WM03`（全面縦巻）。
   - **数値処方・SW連動式**：`ΔD_total = 0.38 × N_tape + D_core_offset + D_taper_built`、`Add_L / Add_R_extra`、`ΔSW = -(W_new - W_base) ÷ 5.0`。
   - **汎用関数公開**：`window.evaluateGripForClub(params)` により、DR以外の全番手（FW/UT/LI/MI_SI/GW/SW）および標準検証テストケース TC-01〜03 を決定論的に評価可能。
3. **ステップ1入力拡充 ＆ 無料気象API（Open-Meteo）連携**
   - ステップ1に「コード（糸入り）の許容度（OK / NG）」「短く握る頻度（標準 / 多い）」のセグメントボタンを追加。
   - ステップ4に **登録不要・無料の Open-Meteo API** による現在地（または標準地点）の気温・湿度自動判定ボタンを追加し、季節モード（通年／夏／冬）と高耐水グリップ要件をワンクリック反映可能（オフライン時は自動フォールバック）。
4. **収録ギア一覧へのグリップ19モデル追加 ＆ v2.9既知CSS不具合修正**
   - カタログに `GRIP_DB`（7メーカー19モデル）の検索・絞り込みテーブルを追加。
   - v2.9の既知課題だった隠し `<select>` の幅膨張（`.field select.visually-hidden-select` の詳細度問題）を修正。

## 使い方

1. `index.html` をブラウザで開く。
2. プリセット（ハードヒッター／アベレージ・スライサー／シニア・女性）で試すか、ステップ1〜3に回答する。
3. ステップ4で **ヘッド×シャフト×グリップ** の総合ベスト10、各順位の工房オーダー処方・4段因果解説、感度分析を確認する。
