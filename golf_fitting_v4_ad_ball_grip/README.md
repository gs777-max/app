## v4.0 での主な変更点（2026-11-21 — 2026年版ボール最適選定エンジン＆4ギアトータル統合）

1. **ボール選定の「ギアトータルランキング」完全マージ**
   - ボール単独の別ランキングではなく、すべての候補（ヘッド14 × シャフト115 × グリップ19）の1組ごとに2026年版ボール選定エンジン（6メーカー・20モデル・2系統因果ロジックツリー）を実行。
   - ギア総合スコアを **ヘッド×シャフト（78%）＋ グリップ（11%）＋ ボール（11%）** へ統合し、ベスト10の各順位カード内に **最適ボールモデル・構造/カバー/硬度目安・DRスピン/弾道/WGスピン・発火ルールID・NG除外・4段因果トレース解説** を一体化表示。
2. **ギア連動クロスカップリング（ヘッド×グリップ×ボール）実装**
   - `R-BG01`：グリップ側で左被り抑制（`R-TP01`）が発火した際、ボール側も低DRスピン＋高均一性モデルへシナジー加点し左OBリスクを二段遮断。
   - `R-BG02`：低スピンヘッド（`-350rpm`超）×低弾道（`low`）の組み合わせでは、極低スピン球（Left Dash / AVX等）を自動除外して二重低スピンによるドロップ失速を防止。
   - `R-CP04`：冬場モード選択時はコンプレッション目標帯を `-6pt` 軟化補正。
3. **ステップ1入力拡充 ＆ カタログ拡張**
   - ステップ1に「優先ゴール（方向安定／飛距離／グリーン周り）」および「グリーン停車力（ツアー系ウレタン必須／標準）」を追加。
   - 収録ギア一覧に `BALL_DB`（6メーカー20モデル）の検索・絞り込みテーブルを追加。
4. **汎用関数公開 ＆ 全テストケース検証済**
   - `window.evaluateGripForClub(params)`（TC-01〜03・競合3 PASS）および `window.evaluateBallForSetup(params)`（TC-B01〜B03 PASS）を搭載。

## v4.0.1 (2026-11-21) — 優先ゴールの重み付け修正

- ライブ確認で発覚：ステップ1の「優先ゴール」（方向安定／最大飛距離／グリーン周り）を切り替えても、表示される結果が何も変わらなかった。原因は2つ：(1) ゴールによる+5点ボーナスが品質スコアの上限100で打ち消されていた（トップ級のボールはすでに上限に達しているため）、(2) ボールの重み11%と整数丸めで合計スコアにも変化が出なかった。
- 修正：ボールの適合スコアの重みをゴールごとに変えた。方向安定は品質重視（DRスピン30%・圧縮25%・品質30%・ウェッジ10%・弾道5%）、最大飛距離はDRスピン・圧縮重視（40%・30%・15%・5%・10%）、グリーン周りはウェッジ重視（20%・20%・20%・30%・10%）。これによりゴール切替でボールの適合スコアが動き、平均的なスイングでは最適ボール自体が変わる（HS 40.5：方向安定→Pro V1、最大飛距離→Z-STAR）。上級者（HS 47）では TOUR B X が全ゴールで最適のまま（全軸でトップ級のボールのため正しい結果）だが、ボール適合スコアは 99.3→99.0→99.5 と動く。
- エンジン・ギア・ゲートに変更なし。バージョン表示のみ v4.0→v4.0.1。
