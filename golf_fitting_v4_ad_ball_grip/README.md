## v4.0.1 (2026-11-21) — 優先ゴールの重み付け修正

- ライブ確認で発覚：ステップ1の「優先ゴール」（方向安定／最大飛距離／グリーン周り）を切り替えても、表示される結果が何も変わらなかった。原因は2つ：(1) ゴールによる+5点ボーナスが品質スコアの上限100で打ち消されていた（トップ級のボールはすでに上限に達しているため）、(2) ボールの重み11%と整数丸めで合計スコアにも変化が出なかった。
- 修正：ボールの適合スコアの重みをゴールごとに変えた。方向安定は品質重視（DRスピン30%・圧縮25%・品質30%・ウェッジ10%・弾道5%）、最大飛距離はDRスピン・圧縮重視（40%・30%・15%・5%・10%）、グリーン周りはウェッジ重視（20%・20%・20%・30%・10%）。これによりゴール切替でボールの適合スコアが動き、平均的なスイングでは最適ボール自体が変わる（HS 40.5：方向安定→Pro V1、最大飛距離→Z-STAR）。上級者（HS 47）では TOUR B X が全ゴールで最適のまま（全軸でトップ級のボールのため正しい結果）だが、ボール適合スコアは 99.3→99.0→99.5 と動く。
- エンジン・ギア・ゲートに変更なし。バージョン表示のみ v4.0→v4.0.1。
