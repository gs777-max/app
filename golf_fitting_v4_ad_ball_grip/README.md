## v4.0.1 (2026-11-21) — 優先ゴールの重み付け修正

- ライブ確認で発覚：ステップ1の「優先ゴール」（方向安定／最大飛距離／グリーン周り）を切り替えても、表示される結果が何も変わらなかった。原因は2つ：(1) ゴールによる+5点ボーナスが品質スコアの上限100で打ち消されていた（トップ級のボールはすでに上限に達しているため）、(2) ボールの重み11%と整数丸めで合計スコアにも変化が出なかった。
- 修正：ボールの適合スコアの重みをゴールごとに変えた。方向安定は品質重視（DRスピン30%・圧縮25%・品質30%・ウェッジ10%・弾道5%）、最大飛距離はDRスピン・圧縮重視（40%・30%・15%・5%・10%）、グリーン周りはウェッジ重視（20%・20%・20%・30%・10%）。これによりゴール切替でボールの適合スコアが動き、平均的なスイングでは最適ボール自体が変わる（HS 40.5：方向安定→Pro V1、最大飛距離→Z-STAR）。上級者（HS 47）では TOUR B X が全ゴールで最適のまま（全軸でトップ級のボールのため正しい結果）だが、ボール適合スコアは 99.3→99.0→99.5 と動く。
- エンジン・ギア・ゲートに変更なし。バージョン表示のみ v4.0→v4.0.1。

## v4.0.4 (2026-11-22) — 改善④の結果を本物の before→after（スピン）に変更

- v4.0.3 の改善④の結果は「キャリー 258y（打出 12.3°・スピン 2150rpm）」だったが、これは誤解を招く表示だった。`trueCarry` はユーザーの入力キャリー（＝今のキャリー）であり、推奨ギアに依存しないため、改善後のキャリーではない。キャリーの before→after はエンジンに正直な計算式がないため出さない（スピン→キャリーの係数がなく、感度分析の HS×5.5 は HS 変化のモデルで今のシャフト重量が不明なため使えず、改善後のミート率もエンジンは計算しない）。
- 代わりに、エンジンが両端を計算しているスピンで本物の before→after を出す。改善④の結果を「スピン 約2600rpm → 目標2150rpm（今のキャリー 258y）」に変更（HS 47 の場合。HS 40.5：約2854rpm → 目標2404rpm、今のキャリー 202y。HS 35：約2350rpm → 目標2700rpm、今のキャリー 165y）。「約〜rpm」はエンジン自身の推定今スピン（`estUserDrSpin`＝黄金目標±450/350rpm）、「目標〜rpm」は黄金ウィンドウの目標値。スピンが既に適正な場合（balanced）は矢印なしで「打出 ○°・スピン ○rpm（今のキャリー ○y）」を表示する。
- チラ見せは④のまま（ロック時はぼかし、①〜③・⑤はマスク）。ダッシュボード・問題点・ゲートの動作に変更なし。エンジン・ギアに変更なし。バージョン表示のみ v4.0.3→v4.0.4。
- 検証：node --check（2スクリプトとも）OK。jsdom 3プリセット（問題点 5/4/4件、改善点 5件、マスク 4・チラ見せ 1、チラ見せ文言は上記の通り、10カード・4ロック、デモ解除→全表示・再ロック復帰、実エラー 0）。CDP 390px＋1280px（文書幅 390／1265、横スクロールなし、0エラー）。
