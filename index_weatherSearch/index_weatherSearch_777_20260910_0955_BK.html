天気予報 （Open‑Meteo / APIキー不要）

都市・地域を指定して、取得可能な範囲（最大16日）の予報を、週ごとに見やすく表示します。

データ提供: Open‑Meteo（無料）

記入例: Tokyo, Osaka, New York, Saitama など

未入力でも検索できます（世界中から候補を検索します）。

Open‑Meteo は最大 16 日分（≒2 週間強）まで取得可能です。3〜4 週間を指定した場合も、取得できる日数の範囲内で表示されます。

よく使う設定は自動保存されます。

候補を選んだら「天気を表示」を押してください。

※ 本ページは Open‑Meteo の無料 API を利用しています（API キー不要）。
※ 予報はあくまで目安であり、実際の天気とは異なる場合があります。
