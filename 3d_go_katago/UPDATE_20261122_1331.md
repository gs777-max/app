## 1. なぜ弱かったか（v2 内蔵AIの実測構造）

- Lv.10 の探索は「rollouts 380回」だが、実体は候補手 上位14手に対する **1手読み＋短いプレイアウト**だった
- プレイアウトは深さ最大36手で打ち切り、19路盤（361点）では対局の序盤しか再現できていなかった
- 評価値は「隣接する石の数」による簡易地計算で、連の死活・地の確定を捉えられなかった

## 2. v3 の最強化内容

### 内蔵エンジン（Worker）を本格 MCTS へ刷新
- **UCT 方式の木探索（MCTS）** を新規実装。候補手を全合法手から prior（従来の戦術ヒューリスティクス）付きで展開し、木を深く読む
- プレイアウトは **終局（両者パス）まで** 実施。プレイアウト方策に「アタリ状態の連の呼吸点を優先（取る／逃れる）」「自分の眼を埋めない」「自殺手回避」を実装
- 終局評価は **洪水填充（flood fill）による地の確定計算**（片方だけに接する空点領域を地とする）へ刷新
- 価値関数は目数差をロジスティック変換した勝率で逆伝播（僅差と大差を区別）

### レベル別予算の引き上げ
| レベル | v2 | v3 |
|---|---|---|
| Lv.7 | 185 rollouts | 700 visits / 最大1.5秒 |
| Lv.8 | 235 | 1,800 visits / 最大3秒 |
| Lv.9 | 300 | 8,000 visits / 最大10秒 |
| Lv.10 | 380 | **30,000 visits / 最大20秒・ノイズ0** |
| Human SL プロ九段 | 290 | 20,000 visits / 最大18秒 |

- 「最強の一手」解析も 240 → 12,000 visits / 最大12秒へ強化
- CPU観戦モードは観戦ペース維持のため思考時間を最大1.5秒に制限

### 本物の KataGo を使うための導線強化（真の最強ルート）
- 外部 KataGo API の既定 maxVisits を 250 → **1,000**、設定上限を 5,000 → **50,000** へ引き上げ
- API URL の入力例を自宅 KataGo 解析サーバ（`http://localhost:8080/analyze`）に変更し、接続テスト（既存機能）で疎通確認できる旨を明記
- KataGo 接続時は内蔵AIより優先される既存の仕様（HybridKataGoController）はそのまま

## 3. 検証結果

- 構文: メイン `<script type="module">` の Node 構文チェック PASS。DOM ID 430個すべて一意（変更前と不変）
- 単体計測（検証用VM。実PCでは数倍速い見込み）: 19路盤 Lv.10 初手で制限時間内に最善手候補が約100〜200 visits まで集中し（12秒設定時 約112 visits／20秒設定時 約201 visits、検証VM実測）、候補は四隅の 3-4／4-4 等の正常な布石点。勝率表示も序盤 約50% と妥当
- 新旧直接対決（Node シミュレーション、中国式計算・コミ6.5）:
  - 9路盤（新＝黒）: 新AI 2勝0敗（+14.5目、+16.5目）
  - 9路盤（新＝白・フル予算）: 新AI 1勝0敗（+25.5目）
  - 13路盤（新＝黒）: 新AI 1勝0敗（+0.5目）
  - 参考: 9路盤で新＝白を極端に短い予算（検証VMの混雑時 約0.55秒/手）にした場合は旧AIの黒に2敗。読みの深さは思考時間に比例するため、Lv.10 の20秒設定が前提
- 全対局で非合法手・エラーなし（エンジン側の合法性チェック通過）

## 4. 正直な限界

- ブラウザ内蔵の純 JavaScript エンジンである以上、GPU で動く本物の KataGo（アマ8段を大きく上回る）には内蔵AI単体では届かない。v3 で内蔵AIは大幅に強くなるが、**アマ8段級に確実に勝ちたい場合は、設定画面から本物の KataGo 解析サーバへ接続することが最強ルート**である
- その接続を前提に、今回の導線強化（visits 引き上げ・入力例・接続テスト）を行った

## 追記: v4 高速化 (2026-11-22 15:5x)

masaki の選択 (A: 内蔵AIの高速化) により、探索エンジンの内部を高速化した。着手ルール・方策・レベル設定の考え方は v3 のまま。

### 高速化の内容
- 連と呼吸点を着手のたびに差分だけ更新する増分管理に置き換え (着手前に全連を数え直す方式を廃止)。着手の取り消しは変更ジャーナルで正確に復元する
- プレイアウトを空点リスト方式に刷新し、合法性と自滅回避を呼吸点数だけで事前判定 (境界ケースのみ厳密計算)
- 地の計算と候補手の事前評価も割当なしの実装に統一
- 高速化で上限が先に効くようになったため、最強系の visits 上限を引き上げ (Lv.10: 30,000→120,000 / プロ九段SL: 20,000→100,000 / 最強の一手解析: 12,000→60,000)。実効は従来どおり思考時間の上限 (Lv.10=最大20秒) で決まる

### 実測 (検証用VM。実PCでは数倍速い見込み)
- 探索速度: 19路 約120→約1,100〜1,380 iterations/秒 (約8〜11倍)、9路 約1,260→約6,100 iterations/秒 (約5倍)
- 19路 Lv.10 初手の最善手 visits: 20秒で約201 (v3) → 約2,970 (v4)。候補は四隅の布石点で妥当
- 正しさの検証: 着手・取り石・自殺手判定と着手取消しをランダム局面460ケースで旧エンジンと照合し不一致0、地の計算は500局面で完全一致
- 同時間対決 (9路、約0.6秒/手、4局): 新旧 2勝2敗・反則手なし。9路では旧版でも読み量が飽和気味で差がつきにくく、高速化の効果が大きいのは19路

### 限界 (変わらず)
- 評価の質そのものは v3 から変わっていない。アマ8段に確実に勝つには、本物の KataGo 解析サーバへの接続が最強ルートである点も変わらない
