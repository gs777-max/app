## 1. 実装・改善項目一覧（①〜⑦）

※ 囲碁のコア対局エンジン（`GoEngine` クラス：着手合法性・劫・アゲハマ・日本/中国/AGA整地・SGF往復・KataGo JSONクエリ生成）および定石チュートリアル問題定義（`TUTORIAL_THEMES` 全8問）にはバグがないため一切手を加えず維持しています。

### ① 両者レベル選択・CPU同士対局モード (`#card-cpu-vs-cpu` / `cpu-vs-cpu`)
- モード選択画面に第6のカード「**猛者 CPU vs CPU 観戦対局**」を追加し、デスクトップ3列×2段の均衡配置に整理しました。
- 詳細設定モーダル（`#setup-modal`）で「CPU観戦」を選択すると `#setup-ai-dual-wrap` が開き、**黒番CPU（Lv.1〜10）**と**白番CPU（Lv.1〜10）**のレベル、進行速度（疾風 `180ms` / 標準 `520ms` / 熟考 `1100ms`）、および召喚する歴代猛者を個別に指定できます。
- 観戦中の上部コンテキストバナー（`#cpu-match-banner`）から、いつでも **一時停止/再開（`#btn-cpu-pause`）**・**進行速度変更（`#sel-cpu-speed`）**・**即整地/終局（`#btn-cpu-finish`）** が可能です。連続パス時は自動で整地確定・AI総評へ進みます。

### ② AI振り返り・課題診断・短期的/長期的改善策・勝負の分かれ目ジャンプ (`#ai-coaching-box`)
- 対局終了時（終局確定・投了・時間切れ）および履歴／検討室（`#review-panel`）起動時に `computeFastWinrateSeries()` と `generateAICoachingReport()` が勝率推移・打ち上げ戦果・局面段階（序盤/中盤/終盤）を自動分析し、以下を具体的に生成します：
  - **勝負の分かれ目（Turning Points）**: 勝率変動や50%跨ぎ逆転が最も大きかった決定的着手（最大4手・#1を最重視）
  - **良かった点・好手 (`#coaching-good-list`)** / **課題・反省点 (`#coaching-bad-list`)**
  - **短期的改善策 (`#coaching-short-list`)**: 次局から即実践できる具体的チェックリスト（実際の分かれ目番手と弱点帯域に連動）
  - **長期的改善策 (`#coaching-long-list`)**: 盤面サイズ・課題帯域に応じた学習ロードマップ
  - **漢詩の一首総評 (`#coaching-poem-box`)**
- 終局結果モーダル（`showMatchResultModal`）および検討室内ボタン（`#btn-jump-decisive-turn` 等）から **`jumpToTurningPoint(moveNum)`** を呼び出すと、**勝負の分かれ目の直前局面（`N - 1`手目）へ即時ジャンプ**し、3D盤面上に金色の「分岐 `#N`」ビーコンを点灯させます。

### ③ 永続対局履歴（中断保存・検索・フィルタ・改名・メモ・お気に入り・削除・詳細メタ情報）
- 終局時だけでなく、**対局を中断してメニューへ戻る／別対局を始める／ページを離脱した際にも** `archiveCurrentMatchIfNeeded()` により自動的に `localStorage`（`memoryHistory`・最大80件、お気に入り優先保持）へ保存され、ゲーム停止〜再開後もいつでも振り返れます。
- 各記録に対戦者名（CPUなら `CPU Lv.X` 明記）・対局日時・盤面サイズ（`w×h`）・コミ・手数・勝敗／途中中断ステータス・任意メモ・お気に入りフラグ（`★`）を保存。
- 履歴モーダル（`#history-modal`）では **すべて / ★ お気に入り / CPU戦フィルタ・キーワード検索・記録名/メモ編集・2段階安全削除・棋譜再生・AI振り返り指南直行** が可能です。

### ④ ヘッダー両者勝率パーセンテージ表示 (`#header-winrate-strip`)
- プレイ中も常時視認できるスリムヘッダー下段に **黒勝率％（`#hdr-winrate-black`）・分割ゲージ（`#winrate-black-bar`）・白勝率％（`#hdr-winrate-white`）** を統合しました。
