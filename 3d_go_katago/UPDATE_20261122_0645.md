## 2. 主な改修内容

### (1) 盤面最優先の空間設計（上下スリムバー＋デフォルト非表示ドロワー）
- **スリム単一行ヘッダー (`#game-header`)**: メニューボタン（`#btn-game-to-menu`）、手番カプセル・コンパクト対局時計（`#hud-clock-black` / `#hud-clock-white` / `#hud-clock-mobile`）、見やすさ切替（`.senior-toggle-btn`）、ツール開閉トグル（`#btn-toggle-studio-drawer`）、下端3pxの極細勝率バー（`#winrate-black-bar`）に集約しました。
- **常時表示・非重複の下部必須操作バー (`#play-action-bar`)**: 対局中に必要な `待った`（`#btn-undo`）、`進める`（`#btn-redo`）、`パス`（`#btn-pass`）、`投了`（`#btn-resign`）、`2D/3D`視点切替（`#btn-quick-view-flip`）、および `ツール` / `閉じる` 開閉ボタン（`#btn-toggle-studio-bottom`）を盤面外の専用ドックに固定し、碁盤や他UIと重ならない構成としました。
- **デフォルト非表示・随時開閉できる対局スタジオドロワー (`#game-sidebar`)**:
  - 通常対局・AI対局・オンライン対局の開始時はデフォルト非表示（`setStudioDrawerOpen(false)`）とし、広い盤面で即座に対局に集中できます。
  - 上下の開閉ボタン（`#btn-toggle-studio-drawer` / `#btn-toggle-studio-bottom`）、ドロワー内閉じるボタン（`#btn-close-studio-drawer`）、およびキーボード **`H` キー** でいつでも表示・非表示を切り替えられます。
  - オーディオ（BGM/効果音）、SGF入出力、設定、表示切替（3D/2D/正面/勢力図/アタリ/全手数/安全入力）、詳細勝率グラフ、対局時計詳細、対戦相手情報、KataGo次の一手・Human SL棋力比較、9路盤チュートリアル、検討室パネルを格納。分析結果がある場合・未読ヒントがある場合はインジケータ（`#drawer-active-dot`）で通知します。
  - チュートリアル開始時および検討モード起動時は該当パネルが必要なため自動でドロワーを開き、閉じれば即座に広い盤面へ戻せます。
  - スマート逆半分確認ルーペ（`#confirm-move-bar` / `positionLoupeBar`）により、安全入力オン時はタップ位置と反対の上下領域に確認バーを配置し、着手予定点の視界を遮りません。

### (2) デザイン・3D盤面と既存機能維持
- 和モダン・ダーク漆塗り基調に微細な麻の葉紋（`Asanoha`）背景パターンを施し、単一ファイル（`index.html` のみ）構成を維持しています。
- Three.js 3D盤面に木目 `bumpMap` を追加し、視点フィット係数（`getFitRadius` の余白係数調整）を最適化して画面内の碁盤存在感を向上させました。
- KataGo WebWorker AI思考、Human SL比較解析、検討モード＆棋譜再生バー（`#replay-bar`）、9路盤チュートリアル8講座、変則盤面（`9×13` など）・置石・リバーサルコミ、4言語対応（日本語 / English / 中文 / 한국어）、標準／シニア（くっきり大文字）プリセット等の既存機能をすべて維持しています。

### (3) 無料・登録不要の公開API活用
- **OGS (Online-Go Server) 公開対局SGF取得**: SGFモーダル（`#sgf-modal`）に `#ogs-game-id-input`・`#btn-ogs-fetch` を追加し、公開対局IDから `https://online-go.com/api/v1/games/{id}/sgf` を直接取得して盤面・検討室へ読み込めるようにしました。
- **QRコード招待生成**: オンライン対局ルーム作成時（`#online-modal`）、共有URL（`?room=XXXXXX` 自動入力対応）を `https://api.qrserver.com/v1/create-qr-code/` で `#created-room-qr` に生成表示します（オフライン時は自動非表示フォールバック）。
- **WebRTC 無料STUNサーバー拡張**: 既存のGoogle STUNに加え、Cloudflare STUN を ICE候補へ追加しました。

### (4) iOS / Windows / macOS マルチデバイス対応
- **iOS**: `apple-mobile-web-app-capable`、`viewport-fit=cover`、`100dvh`、`safe-top` / `safe-bottom` セーフエリア余白、最初の `pointerdown` / `touchstart` での Web Audio `AudioContext` 自動アンロック、Wake Lock（`acquireWakeLock`）を導入しました。
- **macOS**: トラックパッドのピンチジェスチャー（`wheel` イベント `e.ctrlKey`）による3Dズーム倍率操作に対応しました。
- **Windows / レスポンシブ**: モバイル幅（`390×844`）で下部操作ボタンが2行に折り返されないよう短縮閉ラベル `drawer_hide_short`（`閉じる` / `Hide` / `收起` / `닫기`）と `white-space: nowrap` を適用し、シニアモード時も1行収まりを維持しました。
