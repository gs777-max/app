# 役割
あなたは世界最高峰のゲーム開発者、ユニバーサルデザイン（UI/UX）の専門家、3Dグラフィックスエンジニア、そしてボードゲームAI（KataGo / MCTS）のアルゴリズム専門家です。
ブラウザ上で単一のHTMLファイル（`index.html` 1ファイル完結）として即座に動作する、究極の3D囲碁Webアプリケーション **「幽玄 3D囲碁（YUGEN GO）— KataGo Edition」** を作成してください。

# 開発の絶対条件
- **単一ファイル完結**: HTML / CSS / JavaScript をすべて1つの `index.html` にまとめて出力すること。
- **外部リソース**: CDN（Tailwind CSS, Three.js, Google Fonts, Firebase SDK 等）や無料・個人構築のKataGo互換APIの利用は許可するが、画像・音声ファイルは外部アセットに依存せず、すべて HTML5 Canvas / SVG / Three.js / Web Audio API / CSS のプログラム生成で完結させること。
- **完全実装**: 省略やプレースホルダー（`// ここにロジックを実装` など）は一切禁止。すべての機能がそのままブラウザ（Windows PC / iPhone / Android）で完全に動作するコードを出力すること。
- **ダイアログ**: `alert()` / `confirm()` は使用せず、すべてアプリ内の洗練されたカスタムモーダルおよびトースト通知で実装すること。

# 2. 老眼・シニア層にも優しい最高峰の視認性とユーザビリティ（ユニバーサルデザイン）
「見やすさ・押しやすさ・迷わなさ」を最優先に設計してください。
- **視認性プリセット切替（「標準」／「くっきり大文字（老眼配慮）」モード）**をタイトル画面・メニュー・対局ヘッダーに常設：
  - 基本フォントサイズを大きめ（本文16px〜20px以上、勝率や対局時計などの重要数値は24px以上）に設定し、高コントラスト配色（濃い墨色×鮮明な白・金・朱）を採用。
- **盤面の高視認性オプション**：
  - 罫線を太くはっきり描画し、盤外の座標（A〜T、1〜19）を大きく太字で表示。
  - **最終着手マーカー**：直前の石の上に視認性の高い赤×黄の二重リングを表示＋手数番号表示（ON/OFF切替）。
  - **アタリ警告**：呼吸点（ダメ）が残り1つになった石のグループを赤い点滅リングで警告（ON/OFF切替）。
  - **陣地（地合い）のリアルタイム予測表示**：現在の勢力圏を半透明ヒートマップで可視化（ON/OFF切替）。
- **誤タップ完全防止（安全入力モード）**：
  - スマホ・PC問わず、タップ／クリックで一度「着手予定位置の周辺拡大プレビュー（虫眼鏡ズーム枠）」と「ここに打つ／取消」確認バーを表示し、再タップまたはボタンで確定できる安全入力モードをデフォルトON（ON/OFF切替可）にする。
- **ボタン設計**：
  - すべてのボタンのタップ領域は最低 **48px × 48px 以上** を確保し、アイコンだけでなく必ず日本語ラベルを併記すること。

# 4. 厳密な囲碁ルール・置碁・多様な盤サイズ・対局時計
- **厳密な囲碁ルール実装**：
  - 連（グループ）の呼吸点計算と石の打ち上げ、アゲハマカウント。
  - 自殺手の禁止（相手の石を取れる場合を除く）。
  - **Zobrist Hashing** によるコウおよびスーパーコウ（同形反復）の完全禁止。
  - **待った（Undo）／進める（Redo）／パス／投了**、および一度打った後でも何度でも打ち直せる機能。
  - 両者連続パスで終局・整地モードへ移行し、クリックで死石グループを指定・解除して正確に勝敗と目数差を算出。
- **置碁（ハンデ戦）への完全対応**：
  - 置石の数（2子〜9子の星自動配置、さらに盤上クリックによる**自由置石配置**）および**コミ（6.5目、7.5目、0目、逆コミ：黒出し等）**を自由に設定可能。
  - ハンデ戦でも手を抜かず最善を尽くす「上手（うわて）指導碁」として動作。
- **多様なルール・盤サイズ（長方形の変則盤面含む）への対応**：
  - **ルール切替**：日本ルール（地＋アゲハマ＋コミ）／中国ルール／AGAルールを選択可能にし、終局スコア計算に厳密反映。
  - **盤サイズ拡張**：通常の `9×9`、`13×13`、`19×19` に加え、**長方形の変則盤面**（例：`9×13`、`7×9`、`13×19` や任意の縦×横 `5〜19` カスタム設定）を3D碁盤の動的ジオメトリ生成で描画・対局・解析可能にすること。
- **対局時計（持ち時間・秒読み・フィッシャー）**：
  - 時間制限なし（フリー）／持ち時間＋秒読み（例：5分・10分・30分＋30秒×3回等）／フィッシャーモード（初期時間＋1手加算）を選択可能。
  - 大きく見やすいデジタル対局時計を配置し、手番側をハイライト。秒読み突入・残り10秒時は視覚＆Web Audio API音声アラートを発し、時間切れで自動判定。

# 5. KataGo連携（JSON Analysis Engine）＆ 10段階プロ棋士AI ＆ リアルタイム解析
プロ9段以上の棋力を持つKataGo（https://github.com/lightvector/KataGo ）の思想と人気機能を完全に取り込んだ、**「外部KataGo JSON Analysis Engine API 接続」＋「API未設定・オフライン時にシームレスに動作する内蔵Web Worker強化エンジン（MCTS/UCT＋囲碁ドメイン知識）」**のハイブリッド構成を実装してください。

1. **リアルタイム勝率表示＆推移グラフ**
   - 対局中、黒・白のどちらが N% 優勢かをリアルタイムに画面上部の勝率バー・推定目数差・勝率推移スパークラインで常時表示。
2. **「最強の一手」ボタン＆最良手理由解説**
   - 押すとUIを固めずに探索し、上位3候補を盤上に色分けマーカー＋勝率付きで表示。最良手の戦術的理由（打ち上げ、アタリ回避、切断、大場、ヨセ等）をわかりやすく日本語で解説。
3. **10段階AI＆著名プロ棋士オマージュ**
   - 最弱（Lv.1：アマ5級相当）から最強（Lv.10：プロ九段超・世界最強KataGo級）まで10段階で自由に選択可能。
   - 世界中の過去・現在の著名なプロ囲碁棋士をオマージュした名前、**実際のプロ何段相当かの明記**、オリジナルSVGの顔イラスト（ポートレート）、対局中のセリフを表示。
4. **人間らしい打ち方をするモデル（Human SL）＆ 比較検討モード**
   - `b18c384nbt-humanv0` 等を想定し、**「20級〜九段」の指定した棋力らしい手**で対局できるHuman SLモードを実装。
   - **「比較検討モード（自分なら vs プロなら）」**：盤上に「指定棋力の人間が打ちがちな手（青マーカー）」と「プロ・最強KataGoの最善手（緑マーカー）」を同時表示し、思考のギャップを解説。
5. **高速JSON並列解析＆棋譜振り返り室（敗着チェック）**
   - 棋譜全体（全手数）をKataGo Analysis Engine互換JSON形式で一括解析し、全ターンの勝率・目数推移と**悪手・敗着（勝率急落ポイント）を自動検出**。悪手リストからワンタップで該当局面へジャンプして検討・打ち直しができる。
6. **バックエンド・最新アーキテクチャ設定UI**
   - エンジン設定モーダルにて、接続先API URL、認証トークン（任意）、モデルアーキテクチャ選択（従来CNN / v1.17以降の盤面全体のつながりを捉える**Transformerモデル** / Human SL）、推奨バックエンド（NVIDIA CUDA/TensorRT、Mac Metal/CoreML、AMD OpenCL、CPU Eigen、内蔵Web Worker）、JSONクエリプレビュー、接続テスト＆速度計測機能を実装。

  - 正解時は「なぜ良い手なのか」を大きく解説し、不正解時は**相手の反撃を盤上で自動実演して理由を解説**、ワンタップでやり直し可能。クリア進捗を自動保存。

# 7. 自動保存・過去対局ログ・オンライン対戦・SGF入出力
- **自動保存＆途中再開**：対局途中にブラウザを閉じたり通信が途切れても1手ごとに自動保存され、タイトル画面から途中再開できること。
- **過去対局ログ**：終局した対局を自動保存し、いつでも履歴一覧から1手ずつの再生（スライダー・自動再生付き）、AI一括解析、途中の局面からの打ち直し分岐ができること。
- **オンライン対戦**：6桁のルームコードを発行・共有し、離れたスマホ・PC同士でリアルタイムにオンライン対局できること。
- **SGF入出力**：SGF形式のコピー・`.sgf`ダウンロード・テキストからのインポート（そのまま一括解析室へ送る機能含む）を実装すること。
