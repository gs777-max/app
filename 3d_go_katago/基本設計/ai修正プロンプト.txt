# 依頼内容
既存の単一ファイル3D囲碁Webアプリ（`index.html`）を全面的にアップグレードし、以下の追加要件をすべて統合した完全版コード（省略・プレースホルダー一切なし、単一`index.html`完結）を出力してください。

---

# 1. 画面遷移設計（タイトル画面 ＆ モード選択画面）
アプリ起動時にいきなり盤面へ入らず、以下の2段階の導線を和モダンかつ重厚なデザインで実装してください。
1. **タイトル画面（Title Screen）**
   - 幽玄な3D碁盤の背景アニメーション（カメラがゆっくり旋回）＋タイトルロゴ。
   - 大きく押しやすい「対局をはじめる」「続きから再開（自動保存データがある場合のみ表示）」「設定・視認性カスタマイズ」ボタンを配置。
2. **ゲーム選択・モード選択画面（Mode Select Screen）**
   - 以下のモードを大きなカード型UI（アイコン・説明文・段位目安付き）で直感的に選択できるようにする：
     - **KataGo / プロ級AI対局**（プロ9段以上の最強AI、またはHuman SLによる棋力別対局）
     - **置碁・指導碁モード**（ハンデ戦専用セットアップ）
     - **9路盤 定石チュートリアル**（ステップ学習）
     - **棋譜振り返り・AI一括解析室**（過去ログ／SGFの並列解析＆比較検討）
     - **オンライン対人戦 / ローカル2人対戦**

# 2. 老眼・シニア層にも優しい最高峰の視認性とユーザビリティ（ユニバーサルデザイン）
「見やすさ・押しやすさ・迷わなさ」を最優先に設計してください。
- **視認性プリセット切替（「標準」／「くっきり大文字（老眼配慮）」モード）**をヘッダーおよびタイトル画面に常設：
  - 基本フォントサイズを大きめ（本文16px?20px以上、重要数値は24px以上）に設定し、高コントラスト配色（濃い墨色×生成り、またはダーク×鮮明な白/金）を採用。
  - **盤面の高視認性オプション**：罫線を太くはっきり描画、盤外の座標（A?T、1?19）を大きく太字で表示、最終着手マーカーを視認性の高い二重リング＋手数番号表示に切替可能。
  - **誤タップ完全防止**：スマホ・PC問わず、タップ／クリックで一度「着手予定位置の拡大プレビュー（虫眼鏡ズーム枠）」を表示し、「ここに打つ」ボタンまたは再タップで確定できる安全入力モードをデフォルトON（切替可）にする。
  - **ボタン設計**：タップ領域は最低48px×48px以上を確保し、アイコンだけでなく必ず日本語ラベルを併記する。

# 3. 対局時計（持ち時間・秒読み）機能
- 対局設定画面で以下を自由に選択・カスタマイズ可能にする：
  - **時間制限なし（フリー）**
  - **持ち時間＋秒読み（日本ルール式）**：例「持ち時間 5分 / 10分 / 30分」＋「秒読み 30秒 × 3回（または60秒 × 5回）」
  - **フィッシャーモード**：1手ごとに加算（例：初期5分＋1手10秒加算）
- **演出とUI**：
  - 盤面の上下（または左右）に大きく見やすいデジタル対局時計を配置し、手番側をハイライト。
  - 秒読み突入時はWeb Audio APIの合成音声（またはビープ＋読み上げ風カウントダウン音「10、9、8…」「1回目を消費しました」等の視覚＆音声アラート）を実装し、時間切れで自動判定。

# 4. 9路盤の定石チュートリアルモード
- 初心者?有段者まで楽しく学べる**インタラクティブ9路盤チュートリアル**を実装してください。
- **収録カリキュラム（最低6?8テーマ）**：
  1. 基本の初手（天元・星・小目）と陣地の作り方
  2. 9路盤の王道定石（星からのツケ・ハネ・ノビ）
  3. 隅の生き死にと二眼の作り方
  4. シチョウとゲタ（石を取る基本手筋）
  5. ヨセの基本と終局のタイミング
  6. 実践ミニ詰碁・手筋クイズ
- **学習UI**：
  - 盤上に「次に打つべき正解候補」を光るガイドで表示（ヒントON/OFF可）。
  - 正解すると「なぜこの手が良いのか」の解説パネルが大きく表示され、間違えた場合は「なぜ悪手なのか（相手にこう返される）」を自動実演してやり直しできる。
  - 進捗（クリア済みマーク）を自動保存。

# 5. KataGo連携（無料API / ローカル・クラウドAPI接続）＆ KataGo人気機能の完全統合
プロ9段以上の棋力を持つKataGoとの対局および棋譜振り返り分析を実現するため、**KataGo Analysis Engine互換のJSON API連携機能**を実装してください[cite: 1]。
※ブラウザ単体での即時動作も保証するため、**「外部KataGo APIエンドポイント（無料公開API・個人構築クラウドAPI・ローカルプロキシ）を自由に設定して接続するモード」**と、**「API未設定・オフライン時にシームレスにフォールバックして全UI・機能を楽しめる内蔵強化エンジン」**のハイブリッド構成にしてください。

以下のKataGo人気機能をすべてUI・ロジックに取り込んでください：
1. **人間らしい打ち方をするモデル（Human SL）対応**[cite: 1]
   - `b18c384nbt-humanv0` 等の人間棋譜学習モデルを想定し、**「20級?九段」まで希望の棋力プロフィールを指定**して対局・解析できるUIを実装[cite: 1]。
   - **「比較検討モード（自分なら vs プロなら）」**：振り返り時に「指定した棋力（例：5級・初段）の人間が打ちがちな手（青マーカー）」と「プロ・最強KataGoの最善手（緑マーカー）」を盤上に同時表示し、思考のギャップを解説する機能を実装[cite: 1]。
2. **置碁（ハンデ戦）への完全対応**[cite: 1]
   - 置石の数（2子?9子、さらに自由配置）および**コミ（6.5目、0目、逆コミ：黒出し等）**を自由に設定可能にする[cite: 1]。
   - ハンデ戦でも手を抜かず最善を尽くす「上手（うわて）指導碁モード」として、置石の正規配置（星への自動配置）とコミ反映の正確な整地計算を実装[cite: 1]。
3. **多様なルール・盤サイズ（長方形の変則盤面含む）への対応**[cite: 1]
   - **ルール切替**：日本ルール / 中国ルール / AGAルールを選択可能にし、終局時のスコア計算ロジックとコミ基準を各ルールに厳密対応させる[cite: 1]。
   - **盤サイズ拡張**：通常の `9×9`、`13×13`、`19×19` に加え、**長方形の変則盤面**（例：`9×13`、`7×9`、`13×19` や任意の縦×横カスタム設定）を3D碁盤の動的ジオメトリ生成で描画・対局・解析できるようにする[cite: 1]。
4. **高速なJSON並列解析エンジン（Analysis Engine）連携 ＆ 棋譜振り返り室**[cite: 1]
   - 1手ずつのGTP通信だけでなく、**棋譜全体（全手数）をKataGo Analysis Engine形式のJSONリクエストとして一括送信し、全ターンの「勝率・推定目数・オーナーシップ（各地点の地合い領有確率ヒートマップ）」を一括並列取得**するクライアント機能を実装[cite: 1]。
   - 振り返り画面では、全手数の**勝率・目数推移グラフ**を大きく表示し、**「悪手（勝率が急落した局面）」を自動検出してワンタップでジャンプ**できる「敗着チェック機能」を搭載する。
5. **バックエンド・最新アーキテクチャ設定UI**[cite: 1]
   - 高度なエンジン設定パネル内に、接続先API URL、認証トークン（任意）、**モデルアーキテクチャ選択（従来のCNNモデル / v1.17以降の盤面全体のつながりを捉えるTransformerモデル）**[cite: 1]、および**推奨バックエンド情報（NVIDIA CUDA/TensorRT、Mac Metal/CoreML、AMD OpenCL、CPUのみ Eigen）**[cite: 1] の選択・接続テスト・レスポンス速度表示を実装する。
