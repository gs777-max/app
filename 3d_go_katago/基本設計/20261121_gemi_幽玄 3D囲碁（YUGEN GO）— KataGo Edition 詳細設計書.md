# 幽玄 3D囲碁（YUGEN GO）— KataGo Edition 詳細設計書

## 1. プロジェクト概要
### 1.1 コンセプト
ブラウザ上で単一の `index.html` ファイルのみで即座に動作する、世界最高峰の没入感とアクセシビリティを両立した3D囲碁Webアプリケーション。
本榧（ほんかや）の3D碁盤と那智黒・蛤碁石の重厚な和モダン演出、KataGo互換の高度なAI解析・練習機能、さらに老眼・シニア層でも迷わず快適に打てるユニバーサルデザイン（UD）を統合する。

### 1.2 動作・配布要件
- **単一ファイル完結**: HTML / CSS / JavaScript をすべて1つの `index.html` に収める（外部CDNのTailwind CSS・Three.js・Google Fonts・Firebase SDK等は利用可）。
- **マルチデバイス対応**: Windows / Mac のマウス操作、iPhone / Android / タブレットのタッチ操作に完全対応。
- **オフライン・オンライン両対応**: 外部KataGo API未設定時でも内蔵Web Workerエンジンへ自動フォールバックし、全機能が動作すること。

### 2.2 老眼・シニア配慮（ユニバーサルデザイン仕様）
- **視認性プリセット切替（「標準モード」／「くっきり大文字モード」）**
  - ヘッダーおよびタイトル画面からワンタップで切替可能。
  - **フォントサイズ**: 標準16px、大文字モード時はルート19px〜20px以上、勝率・対局時計などの重要数値は24px〜30px相当で強調。
  - **高コントラスト配色**: 盤面・UIパネルの枠線を太く鮮明にし、黒・白・金・朱の視認性を最大化。
- **盤面視認性オプション**
  - 太く明瞭な罫線、大きく太字の盤外座標（`A〜T`、`1〜19`）。
  - 最終着手マーカー：赤×黄の高視認性二重リング表示。
  - 手数番号表示（ON/OFF）、アタリ警告の赤リング点滅（ON/OFF）、勢力図ヒートマップ（ON/OFF）。
- **誤タップ完全防止（2段階安全入力モード：デフォルトON）**
  - 交点タップ／クリック時に即座に着手せず、着手予定位置の周辺を拡大描画する**虫眼鏡ズームプレビュー枠**と「ここに打つ／取消」フロートバーを表示。再タップまたは確定ボタンで着手する。
- **ボタン・操作性設計**
  - すべてのインタラクティブボタンは **48px × 48px 以上** のタップ領域を確保。
  - アイコンのみのボタンは禁止し、必ず日本語ラベルを併記。

## 3. 3Dグラフィックス＆サウンド設計

### 3.1 Three.js 3Dレンダリング設計
- **本榧碁盤（動的ジオメトリ生成）**
  - 通常の正方形盤面（`9×9`、`13×13`、`19×19`）に加え、**長方形の変則盤面**（`9×13`、`7×9`、`13×19`、および `5〜19` の任意カスタム縦×横）に応じて3Dボックスの縦横比・テクスチャ・交点座標を動的に再構築する。
  - Canvas APIによるプロシージャル木目・罫線・星・大座標テクスチャ生成。
- **碁石マテリアル＆アニメーション**
  - **黒石（那智黒）**: マットな質感と微細な粒状ノイズ。
  - **白石（蛤碁石）**: 上品な光沢と微細な縞模様テクスチャ、立体ドロップシャドウ。
  - 着手時の落下アニメーション、ホバー時の半透明ゴースト石、着手禁止点への赤い「×」マーク表示。
- **カメラ・視点操作**
  - タイトル画面では3D碁盤をゆっくり自動旋回。
  - ドラッグ／スワイプによる自由回転、ホイール／ピンチによるズーム、「3D立体」「2D真上」「正面リセット」のワンタップ切替。

### 3.2 Web Audio API サウンド設計（外部音声ファイル不要）
- **打石音**: バンドパスフィルタをかけたノイズバースト＋低音三角波の合成による乾いた「パチッ」音。
- **アゲハマ音**: 打ち上げ石数に応じた連続高音サイン波。
- **パス音・成功ファンファーレ・秒読みビープ**: 残り10秒〜1秒のカウントダウン警告音（残り3秒以下は高音で切迫感を演出）。
- **和風アンビエントBGM**: 陰旋法（都節音階）ベースのジェネレーティブ和風サウンド（ON/OFF切替）。

## 4. 囲碁ルール・ゲームロジック設計

### 4.1 厳密な囲碁ルールエンジン（`GoEngine`）
- **盤面表現**: `Int8Array(width * height)` による高速管理（長方形盤面対応）。
- **連結・呼吸点（ダメ）計算**: BFS/DFSによる連（グループ）と呼吸点集合の正確な算出、呼吸点0での打ち上げおよびアゲハマ加算。
- **自殺手禁止**: 相手石の打ち上げを伴わない呼吸点0の着手を完全禁止。
- **コウ・スーパーコウ判定**: 64bit相当の **Zobrist Hashing** で過去すべての盤面ハッシュを履歴保持し、同形反復を厳密に禁止。
- **置碁（ハンデ戦）＆自由置石**:
  - 2子〜9子の星への自動配置（白番開始）。
  - 盤上クリックで黒石を任意配置・解除できる「自由置石配置モード」。
  - コミ自由設定（`6.5`、`7.5`、`0`、逆コミ `-5.5` などの黒出しに対応）。
- **複数ルール＆整地（終局計算）**:
  - **日本ルール**: 地＋アゲハマ＋死石＋コミ
  - **中国ルール / AGAルール**: 地＋盤上の生きた石＋コミ
  - 両者連続パスで整地モードへ移行し、クリックで死石グループを指定・解除、リアルタイムに目数差を表示して終局確定。
- **Undo / Redo**: スナップショットスタックによる無制限の「待った」「進める」および棋譜再生中の任意局面からの打ち直し分岐。

### 4.2 対局時計（`GameClock`）
- **対応方式**:
  1. 時間制限なし（フリー対局）
  2. 持ち時間＋秒読み（例：5分/10分/30分 ＋ 30秒×3回 / 60秒×5回）
  3. フィッシャーモード（例：初期5分＋1手10秒加算 / 初期10分＋1手15秒加算）
- **機能**: 手番ハイライト、秒読み突入通知、残り10秒の音声＆視覚アラート、時間切れによる自動勝敗判定・履歴保存。

## 5. KataGoハイブリッドAI・解析・学習機能設計

### 5.1 ハイブリッドエンジン構成（`HybridKataGoController`）
1. **外部KataGo JSON Analysis Engine API 連携モード**
   - ユーザーが設定画面から外部エンドポイントURL・認証トークンを指定可能。
   - KataGo Analysis Engine互換のJSONクエリ（`boardXSize`, `boardYSize`, `rules`, `komi`, `initialStones`, `moves`, `includeOwnership`, `maxVisits`, `overrideSettings`）を生成・送信。
   - **アーキテクチャ・バックエンド設定UI**:
     - モデル選択：`Transformer v1.17+`（盤面全体のつながり特化）／`CNN b18c384nbt`／`Human SL b18c384nbt-humanv0`
     - 推奨バックエンド表示・設定：NVIDIA CUDA/TensorRT、Mac Metal/CoreML、AMD OpenCL、CPU Eigen、内蔵Web Worker
     - 接続テスト＆レスポンス速度計測機能。
2. **内蔵Web Worker ハイブリッドエンジン（フォールバック＆即応）**
   - メインスレッドをブロックしないWeb Worker上で、MCTS/UCT（モンテカルロ木探索）＋囲碁ドメイン知識（眼保護、アタリ回避・追撃、星・小目・三々・辺のヒラキ、切り・連絡、ヨセ評価）を実行。

### 5.2 著名プロ棋士オマージュ 10段階AI ＆ Human SL
- **10段階AIプロファイル**:
  - Lv.1（アマ5級相当）〜 Lv.10（神算・アルファ九段 / プロ九段超 KataGo級）まで10名のオリジナル棋士を定義。
  - 各棋士にプロシージャル生成のSVG肖像画、実際のプロ段位目安、棋風パラメータ、対局セリフを設定。
- **Human SL（人間らしい棋力モデル）**:
  - `20級` 〜 `プロ九段` の棋力を指定して対局可能。
  - **比較検討モード（青：指定棋力の人間 vs 緑：プロ・最強KataGo）**: 両者の推奨手を盤上に同時プロットし、思考のギャップを日本語で解説。

### 5.3 リアルタイム評価・最強の一手・一括棋譜解析室
- **リアルタイム勝率バー＆推移グラフ**: 1手ごとに黒・白の勝率（N%）、推定目数リード、SVGスパークラインを更新。
- **最強の一手（理由解説）**: 上位3候補を盤上に色分けマーカー＋勝率付きで表示し、戦術タグ（打ち上げ・アタリ回避・切断・大場など）と日本語解説を提示。
- **棋譜振り返り・AI一括解析室**: 過去ログまたはSGF全手数を一括並列解析し、勝率が急落した「悪手・敗着」をリスト抽出。ワンタップで該当手直前へジャンプして検討・打ち直しが可能。

### 5.4 9路盤 定石チュートリアル
- **全6テーマ構成**:
  1. 基本の初手（天元・星・小目）と陣地
  2. 9路盤の王道定石（星からのツケ・ハネ）
  3. 隅の生き死にと二眼の作り方
  4. シチョウとゲタ（石を取る基本手筋）
  5. ヨセの基本と終局のタイミング
  6. 実践ミニ詰碁（三目中手）
- **インタラクティブ学習**: 光るガイド（ヒントON/OFF）、正解時の理由解説、**不正解時の相手反撃自動実演**、クリア進捗の自動保存。

## 6. データ永続化・オンライン対戦・SGF仕様
- **自動保存・途中再開**: 1手ごとに盤面設定・着手履歴をクラウド（Firebase Firestore）またはローカルメモリへ自動保存し、アプリ再起動・途中離脱後も再開可能。
- **過去対局ログ**: 終局時に日時・盤サイズ・対戦相手・勝敗・全棋譜を保存し、一覧から再生・一括解析・途中打ち直しが可能。
- **オンライン対人戦**: 6桁ルームコードを発行・共有し、Firestoreのリアルタイムリスナー（`onSnapshot`）でスマホ・PC間の着手を即時同期。
- **SGF入出力**: 長方形盤面（`SZ[W:H]`）・置石（`AB`）・コミ（`KM`）・ルール（`RU`）に対応したSGFエクスポート／インポート機能。
