# 2. 実装必須の「3段階フィルタリング × 6大物理分析アルゴリズム」
JavaScript内に以下の処理パイプラインを実装し、計算過程の数値も診断サマリーに表示してください。

## 【前処理：デタラメ入力・矛盾値の自己修復フィルタ】
- スマッシュファクター `SF = BS ÷ HS` が物理限界（`1.30 <= SF <= 1.515`）を外れる場合、または `BS` 未入力時は、打点オフセット距離 `d(mm)` から `SF = 1.495 - 0.0035 * d - 0.0008 * |FaceToPath|^2` で自動補正。
- `総飛距離 < キャリー`、`ラン > 65yd`、`キャリー > HS * 6.15`、または距離未入力時は「距離データ無効フラグ（`INVALID_DIST_FLAG = true`）」を立て、HS・球の高低・打点から真のキャリーとランを物理推計する。

## 【第1段階（Stage 1）：スクリーニング】総重量フロー ＆ HSによる「重さ・硬さ」の大枠決定
1. **7番アイアン基準の総重量フロー計算式**：
   - 7番アイアン推定総重量 `W_7I` から、ドライバーの理想総重量 `W_1W_total = 0.72 * W_7I + 16.0 + ΔW_phys`（約270g〜335g）を算出。
   - そこからヘッド重量（約200g）・グリップ重量（約50g）・スリーブ重量（約9g）を引き、**理想シャフト重量 `W_shaft_ideal`（30g台〜80g台）**を決定する（アイアン不明時は `1.45 * HS - 2.0 + 体格年代補正` で算出）。
2. **梁理論の固有振動数 `f_cpm` によるフレックス決定**：
   - `f_cpm = 4.35 * HS + 62 + 1.8 * TempoIndex` から目標振動数（cpm）を計算し、`L / R2 / R / SR / S / SX / X / TX` の全フレックスから適正範囲をスクリーニングする。

## 【第2段階（Stage 2）：方向性・打点補正】インパクトダイナミクス × 仮想スイングDNA × 打点ギア効果
1. **9つの飛球線イラストからのD-Plane完全逆算**：
   - `θ_launch(出球角) = 0.85 * FaceAngle + 0.15 * ClubPath` の逆行列により、選択された9弾道の絵から「出球方向（左・中・右）」「インパクトフェース角」「クラブパス」「フェーストゥパス」を自動算出。
2. **ローテーション量によるヘッド分類（リストターン型 vs ボディターン型）**：
   - 野球・テニス経験者やドロー/フック・逆球傾向（フェース開閉大）には「重心距離が短め〜標準で操作性の高い浅重心ヘッド（Tour LS / Core）」、ボディターンでフェース向きを変えないタイプや直進志向には「深重心・高MOIの大型ヘッド」を適合させる。
3. **仮想スイングDNA（①テンポ・②トゥダウン量・③キック角）によるEIプロファイル（調子）決定**：
   - テンポが速くタメが強い（キック角小・レイトヒット）＋左ミス抑制には「元調子〜中元調子（手元しなり・先端超硬）」。
   - 球を捕まえたい・打ち出しを上げたい（キック角大）には「先中調子〜中調子」。
4. **打点5領域 × 10,000 $\text{g}\cdot\text{cm}^2$（10K）MOI判定 ＆ ヒール下打点の矛盾解消分岐**：
   - FWキープ数 $\le 5$ または OB数 $\ge 2.5$ の場合、打点標準偏差 $\sigma$ が大きいと判定し、**合計MOI 10,000 $\text{g}\cdot\text{cm}^2$ クラス（PING G440 MAX / K、Qi35 MAX、ELYTE X、G440 LST等）**のスコアを引き上げる。
   - **「ローヒール（下・根元）」打点の軌道別2分岐**：
     - **分岐A（HS 43m/s以上 または フック・ドロー系がローヒールに当てる場合）**：ダウンスイングの遠心力による鉛直トゥダウン変形 `δ_toe ∝ (m_h * e * HS^2 * L^3) / EI_tip` と下部ヒットの縦ギア効果スピン増が原因であるため、**「①クラブ長を 45.0〜45.25 inch へ短尺化、②スリーブをフラットライ角に設定、③前方ウェイト増量、④カウンターバランス（TENSEI Pro Orange 1K等）または超低トルク・先端高剛性シャフト」**を強制指定する。
     - **分岐B（HS 42m/s以下 かつ スライス系がローヒールに当てる場合）**：カット軌道によるヒール擦りスライス＆ドロップが原因であるため、**「重心距離が短めで捕まりやすく、高MOI・深重心で初速ロスを補うヘッド ＋ 中〜先中調子シャフト」**を指定する。

## 【第3段階（Stage 3）：飛距離最大化】HS別・黄金ウィンドウ × ギャップ決定木 × 季節微調整
1. **吹き上がり・ドロップの2段階ハイブリッド判定**：
   - **第1優先**：事前確認の「球の高低イラスト（①〜⑤）」が選択されていれば、そこから現在の打ち出し角とスピン状態を直接判定。
   - **第2優先（フォールバック）**：球の高低が「⑥分からない」または距離入力がデタラメな場合、「総飛距離 － キャリー ＝ ラン」と「BS ÷ HS ＝ ミート率」（および打点上下位置の縦ギア効果）から推定バックスピン量 `ω_est (rpm)` と打ち出し角を算出。
2. **HS別・理想ウィンドウとのギャップ補正決定木（デシジョンツリー）**：
   - HS別の理想ウィンドウ（例：HS 40m/sなら14〜16°・2250〜2600rpm、HS 47m/sなら11.5〜13°・2000〜2300rpm）と比較し：
     - 「高スピン＋高打ち出し（吹き上がり）」$\rightarrow$ 浅重心LSヘッド ＋ ロフト角 8.0°〜9.0°（スリーブ `-1.0°` オープン化）＋ 前方重ウェイト。
     - 「高スピン＋低打ち出し」$\rightarrow$ 低・浅重心ヘッド（縦ギア効果でスピンを減らす）＋ ロフト角は維持（9.5°〜10.5°）。
     - 「低スピン＋高打ち出し」$\rightarrow$ 浅〜中重心ヘッド ＋ 低ロフト設定で推進力を最大化。
     - 「低スピン＋低打ち出し（ドロップ）」$\rightarrow$ 深重心ヘッド ＋ 高ロフト（10.5°〜12.0° またはスリーブ `+1.0°`）＋ 後方重ウェイト。
3. **季節別（通年・春秋 ／ 夏場 ／ 冬場）の動的切り替えタブ**：
   - **夏場モード**：身体が回りHS上昇・発汗・芝抵抗大 $\rightarrow$ ロフト `-0.5°〜-1.0°`（オープン＆フラット）、前方ウェイト増、重硬シャフト、コード入りグリップ。
   - **冬場モード**：低温・空気密度 $+10\%$・厚着でHS `-1.2m/s` 低下 $\rightarrow$ 現クラブのロフト `+0.5°〜+1.0°` ＆ 後方ウェイト化、および夏用より `-5〜-10g` 軽い（または中元がしなる）冬用サブシャフトを提案。
