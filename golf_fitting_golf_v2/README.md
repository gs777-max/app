# FIT LAB — Driver Fitting v2.8

絵を選ぶだけのドライバーフィッティング診断。単一ファイル `index.html` のみで動作します（Google Fonts のみ外部読み込み。Tailwind 不使用）。

公開URL（GitHub Pages）：`https://gs777-max.github.io/app/golf_fitting_golf_v2/`

## 使い方

1. `index.html` をブラウザで開く。
2. ヒーローのプリセット（ハードヒッター／アベレージ・スライサー／シニア・女性）で試すか、ステップ 1〜3 に答える。
   - ステップ 1：あなたについて（体格・スポーツ経験・テンポ・7番アイアン）
   - ステップ 2：球の高さと飛距離（絵＋数値。分からない項目は「わからない」にチェック）
   - ステップ 3：球筋と打点（9弾道イラスト＋フェース5領域）
3. 「診断する」でステップ 4（結果）を表示。季節モード（通年／夏／冬）で再計算できる。

## 診断ロジック（仕様書 v3.0 に基づく 3段階フィルタ）

1. **スクリーニング**：7番アイアン総重量からドライバー目標総重量 `W₁W = 0.72 × W₇I + 16.0 ＋補正` を求め、シャフト重量 ＝ 総重量 − 200（ヘッド）− 50（グリップ）− 9（スリーブ）に一意化。固有振動数 `f = 4.35 × HS + 62 + 1.8 × テンポ` でフレックスを絞る。
2. **方向性・打点補正**：9弾道から D-Plane 式でフェース角・パスを逆算。FWキープ数・OB数から 10,000g·cm²級の高MOIヘッド要否を判定。ローヒール打点はハードヒッター／スライサーで対策を分ける。
3. **飛距離最大化**：HS別 理想打ち出し角・スピンウィンドウ（仕様書 §3-1 の6点表を線形補間）と今の球の高さの差から、ロフト・スリーブ・ウェイトを決定木で調整。

矛盾する入力（ミート率が 1.30〜1.515 を外れる、キャリー＞総飛距離など）は破棄し、打点とHSから物理推計した値に置き換える（結果画面のバッジで通知）。

## 既知の課題・未検証項目

- **隠しselectの幅が1pxになっていない（v2.5検証で発見・次回候補）**：`.visually-hidden-select{width:1px}` が `.field select{width:100%}`（詳細度0,1,1）に負け、6個の隠しselectが約1265px幅になり、横方向のscrollWidthが1593pxまで膨らんでいる。`html,body{overflow-x:clip}` のため横スクロールは発生せず、透明・非操作のため現在は実害なし。修正は `.field select.visually-hidden-select{width:1px;min-height:0}` 等の詳細度引き上げ。
