## 3. 今回（2026-11-16 21:09）の主な更新・バグ修正内容

### 3-1. 物理エンジン・マッチング精度の修正（Layers 1〜6）
1. **許容トルク窓（Layer 4 `tauFormula` / `tauAllow`）の物理スケーリング改善**
   - 仕様書の基本式 `τ_formula = 6.8 - 0.08×HS - 0.25×AntiLeftLv - 0.20×Penalty` を維持しつつ、実シャフトカタログ帯に合わせた実効許容上限 `tauAllow` を導入。
   - 高HS（HS 47m/s・プルフック・ローヒール）の `上限 3.2°` 要件と、低HS・軽量（HS 33m/s・30g〜40g台）の高トルクシャフト（例：VANQUISH 3R2）の双方で不当な減点を解消。
2. **浅・低重心LSヘッド指定時の要求MOI競合の解消（Layer 1 / Layer 3 / Layer 5）**
   - 吹き上がり（`traj=5`）やローヒール打点（`impact=LH`）では浅重心LSヘッド＋前方ウェイトが推奨されるにもかかわらず、一律で `moiReq` を高く要求して LS ヘッドや前方ウェイトが減点されていた問題を修正。
3. **HS連動・実効ロフト角の下限/上限ガード（Layer 6）**
   - HS 40〜43m/s 帯で極端な低ロフト（7.5°等）が選出されないよう、HS帯別の実効ロフト適正範囲（`minLoft〜maxLoft`）を設定。
4. **着弾後ラン計算（`rollModel`）の物理モデル改善**
   - 水平着弾速度 $v_h^2$ と落下角・バックスピン減速を反映し、低HSドロップ弾道で非現実的な過大ラン（70yd）が出る不具合を修正。
5. **総合スコア重み・係数のキャリブレーション**
   - 理想マッチが 80〜99 点台、シニア・軽量帯でも適正帯で整合したスコア順位になるよう `K=35` および `dSpin` / `dTq` スケールを調整。

### 3-2. クロスデバイス（iOS / Windows / macOS）対応・バグ修正
1. **iOS Safari セーフエリア・ズーム防止**
   - `.ticker` の外側ラッパに `padding-top: env(safe-area-inset-top, 0px)` を分離し、iPhone のノッチ／Dynamic Island 環境でティッカー文字が潰れる問題を解消。
   - 地名検索欄を含む全入力欄の文字サイズを `16px` 以上に設定し、iOS Safari でのフォーカス時自動ズームを防止。
   - `html, body` の双方で横はみ出しを抑制し、モバイル幅 `390px` での `scrollWidth === 390px`（横スクロール 0）を確認。
2. **全角数字入力（日本語IME）対応**
   - 数値入力欄を `type="text" inputmode="decimal"` に変更し、`toAscii()` 正規化を追加。iOS では数値テンキーを出しつつ、Windows / macOS で全角数字（例：`１７５`）を入力しても自動変換して受け付けるよう改善。
3. **チャート・タイポグラフィ・プリント修正**
   - マストヘッド見出しのサブタイトル文字サイズを調整し、不自然な折り返し（1文字改行）を解消。
   - `#bench` / `#result` に `scroll-margin-top: 46px` を付与し、固定ティッカーによるタイトル隠れを防止。
   - RK4弾道グラフで「現状」と「BEST1」の総飛距離ラベルが近接した際の重なりを自動回避。
   - `@media print` で SVG 描画アニメーションを即時完了状態に固定し、印刷・PDF保存時の途中欠けを防止。
