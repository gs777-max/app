# 1. ユーザー入力UI設計（初心者でも詳しい人でも答えられるデュアル設計）
数値入力欄にはすべて「分からない／自動推計」ボタンまたはスライダー補助を設け、イラスト（SVG）をタップして直感的に選べるUIを実装してください。

## A. フィジカル＆バックグラウンド
- **性別**：男性 / 女性 / その他
- **年代**：20代 / 30代 / 40代 / 50代 / 60代 / 70代以上
- **身長・体重**：身長(cm)・体重(kg)
- **スポーツ経験**：野球、テニス、卓球、ホッケー、剣道、水泳、陸上、サッカー、ゴルフ専念など（切り返しでの前腕回旋トルク・ラグ生成量の計算に使用）

## B. 弾道データ＆事前確認「球の高低」（★ハイブリッド判定用）
- **【事前確認】見た目の球の高さ（横から見た5段階の弾道シルエットSVGで選択＋「分からない」）**：
  1. ライナー・低弾道（浮き上がらず早めに落ちる）
  2. 中低弾道・強弾道（風に強くライナー性で転がる）
  3. 標準・中弾道（理想的な放物線）
  4. 高弾道（高く上がってキャリーが出る）
  5. 吹き上がり・超高弾道（途中でホップして真上から落ち、転がらない）
  6. 分からない・バラバラ（→距離と初速の計算ロジックへ自動委譲）
- **ヘッドスピード (HS)**：m/s（分からない場合は「7番アイアンの飛距離」または「ドライバーの飛距離目安」から自動逆算）
- **ボールスピード (BS)**：m/s（任意入力。未入力または物理的矛盾値の場合は打点とHSから自動算出）
- **平均キャリー (yd)** ＆ **総飛距離 (yd)**（任意入力）
- **18Hの平均FWキープ数**（0〜14H）＆ **平均OB数**（0〜10発）

## C. 飛球線（9つの弾道イラスト選択）＆ フェース打点（5領域イラスト選択）
- **飛球線（D-Plane 9弾道：上から見た飛球線SVGイラストカード9枚＋「左右両方に散る」から選択）**：
  ※「出球方向（左・中・右）」は個別質問せず、この9つの弾道イラストの選択結果から内部要素として自動算出すること。
  1. 【左へ飛び出し、さらに左へ巻く】（プルフック / チーピン）
  2. 【左へ飛び出し、そのまま真っ直ぐ左へ行く】（プルストレート）
  3. 【左へ飛び出し、右へ曲がって戻る】（プルフェード / プルスライス）
  4. 【真っ直ぐ飛び出し、左へ曲がる】（ストレートドロー / フック）
  5. 【真っ直ぐ飛び出し、真っ直ぐ飛ぶ】（ストレート）
  6. 【真っ直ぐ飛び出し、右へ曲がる】（ストレートフェード / スライス）
  7. 【右へ飛び出し、左へ曲がって戻る】（プッシュドロー / プッシュフック）
  8. 【右へ飛び出し、そのまま真っ直ぐ右へ行く】（プッシュストレート）
  9. 【右へ飛び出し、さらに右へ曲がる】（プッシュスライス）
  10. 【球によって右にも左にも大きく散る】（逆球・タイミング不安定）
- **スイングプレーン（任意・自己認識）**：インサイドアウト / インサイドイン（オンプレーン） / アウトサイドイン / 分からない（9弾道から自動逆算）
- **ドライバーフェースの当たりやすい場所（フェース正面SVGの5領域クリック選択）**：

# 2. ノーベル物理学賞×ティーチングプロの分析アルゴリズム（実装必須ロジック）
以下の6つの物理演算レイヤーをJavaScriptコード内に正確に実装してください。

1. **【Layer 0：デタラメ入力・矛盾値の自己修復フィルタ】**
   - スマッシュファクター `SF = BS ÷ HS` が物理限界（`1.30 <= SF <= 1.515`）を外れる場合、または `BS` 未入力の場合は、打点オフセット距離 `d(mm)` から `SF = 1.495 - 0.0035 * d - 0.0008 * |FaceToPath|^2` で自動補正。
   - `総飛距離 < キャリー`、`ラン > 65yd`、`キャリー > HS * 6.15`、または距離未入力の場合は「距離データ無効フラグ」を立て、HS・球の高低・打点位置から真のキャリーとランを物理再計算する。
2. **【Layer 1（Step 1）：吹き上がり・ドロップの2段階ハイブリッド判定】**
   - **第1優先**：事前確認の「球の高低（5段階）」が回答されていれば、マグヌス揚力と抗力のバランスから吹き上がり（高スピンロス：⑤）またはドロップ（低スピン失速：①）を直接判定。
   - **第2優先（フォールバック＆精密検証）**：球の高低が「未回答（分からない）」または距離・初速入力がデタラメな場合、「総飛距離 － キャリー ＝ ラン」と「BS ÷ HS ＝ ミート率」のロジック（および打点上下位置の縦ギア効果式）を発動し、バックスピン量 `ω(rpm)` と最適ロフト角・重心深度（LS / Core / MAX）を算出。
3. **【Layer 2（Step 2）：9弾道ビジュアルからの出球・フェース角・軌道ベクトル逆算】**
   - D-Plane方程式 `θ_launch(出球角) = 0.85 * FaceAngle + 0.15 * ClubPath` および `SpinAxis(傾き) ∝ (FaceAngle - ClubPath)` に基づき、選択された9弾道の絵から「出球方向（左・中・右）」「インパクトフェース角」「スイング軌道」「必要な重心角＆スリーブフェース角補正量（Anti-Left Lv.1〜3 / Neutral / Draw-Bias Lv.1〜3）」を自動算出。
4. **【Layer 3：遠心力トゥダウン変形 `δ_toe` × 打点5領域の3Dギア効果演算】**
   - ダウンスイング時のヘッド重心距離 `e` による鉛直トゥダウン量 `δ_toe ∝ (m_head * e * HS^2 * L^3) / EI_tip` を計算。
   - **ローヒール打点**の場合：「トゥダウン過多＋下部ヒットの縦ギア効果スピン増（+500rpm）＋先端当たり負け」と診断し、①クラブ長を `45.0〜45.25 inch` へ短尺化、②スリーブをフラットライ設定、③前方重ウェイト、④超低トルクまたはカウンターバランスシャフト（先端高剛性）を強制指定。
   - **ハイトゥ打点**の場合：「縦ギア効果によるスピン激減（-500rpm）＋横ギア効果による強ドロー回転」と診断し、高MOIヘッド＋適正ロフト確保＋先端安定シャフトを指定。
5. **【Layer 4：全重量帯（30g〜80g台）・全フレックス（L/R2〜TX）の連続値算出】**
   - 6X・7Xに限定せず、アイアン重量連動式 `W_ideal = 0.45 * W_iron + 14.5 + ΔW` およびHS・体格・年齢から、30g台〜80g台の理想重量を1g単位で算出。
   - オイラー・ベルヌーイ梁の固有振動数式 `f_cpm = 4.35 * HS + 68 + Δf_tempo + Δf_sport` から適正振動数（cpm）とフレックス（R2 / R / SR / S / SX / X / TX）を決定。
   - スリクソン「インターナショナル・フレックス・コード（IFC：4桁）」は参考指標として各シャフトに併記。
6. **【Layer 5 & 6：季節別（通年・夏・冬）熱力学補正 ＆ 2026年11月全モデルベスト10出力】**
   - 夏場（高温・HS上昇・芝抵抗大・汗滑り）と冬場（低温・空気密度+10%・厚着によるHS -1.2m/s低下）のタブ切り替えにより、スリーブ調整・ウェイト配分・冬用サブシャフトを含むベスト10（100点満点スコア・ヘッド・シャフト・フレックス・長さ・参考IFC・スリーブ・ウェイト・グリップ下巻き枚数・物理的根拠）を出力。
