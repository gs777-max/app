## 修正プロンプト集（開発AIへそのまま渡せる形式）

### P0ポーカーで「コール／レイズ／オールイン」ボタンが無反応

```
現象（実機再現済み）：ポーカーでプレイヤーの手番に「コール(20)」「レイズ」「オールイン」を
クリックしても、チップ・POT・アクションログが一切変化せず進行できません。
2ハンドにわたり計3回試行してすべて無反応でした。一方「フォールド」は即座に反応し、
その後はAI同士でフロップ→ターン→リバー→ショーダウンまで正常に進行します。
つまりプレイヤーはフォールド以外で参加できません。
調査の起点：render() が毎手番ごとにコントロールを再生成している点、
btnCall/btnRaise/btnAllIn の disabled 判定（myTurn = turn===0 の算出タイミング）、
applyAction(0, 'check_call'|'raise'|'allin') の呼び出しと例外発生の有無、
3D視点（CSS transform）時のクリック座標のずれを疑ってください。
修正後、プリフロップでコール→フロップ到達、レイズ→AIの応答、オールイン→ショーダウンまでを
実機で通し確認し、結果を報告してください。
```

### P1 ポーカーの POT 表示が中央とサイドバーで食い違う

```
現象：ショーダウン直後、テーブル中央の POT 表示（420）とサイドバーの POT 表示（380）が
一致しませんでした。サイドバーのプレイヤー情報（setPlayersUI の meta）は processTurn() でしか
更新されず、ショーダウン確定時の再描画で古い値が残るのが原因とみられます。
ポット確定・配分後も全表示箇所のチップ/POTが一致するよう、表示更新のタイミングを統一してください。
あわせて、サイドポット未実装（オールイン額が異なる場合の配分）について、
現状の配分ロジック（勝者への均等分割）が正しいか検証し、問題があればサイドポットを実装してください。
```

### P2 将棋の「待った」で時計がリセットされない

```
現象：将棋で2手進めた後に「待った」を押すと盤面と棋譜は初期状態に戻りますが、
持ち時間は戻りません（後手09:59／先手09:22のまま）。
「待った」の仕様を決めてください：(a) 盤面を戻すだけなら時計も消費時点まで巻き戻す、
(b) 対局そのものをやり直すなら新規対局と同様に両時計10:00へ。
どちらを採るか明記し、チェス側の待ったも同じ仕様に揃えてください。
```

### P3 チェスの棋譜でポーンの着手が「♔ e4」と記録される

```
現象：ポーン e2→e4 の着手が、棋譜に王の記号「♔ e4」と記録されました。
formatNotation() の駒記号の対応表（ポーンは記号なし、または "P"）を確認し、
全駒種で正しい代数式記譜（N/B/R/Q/K、ポーンは無印、キャスリングは O-O / O-O-O、
チェックは +、メイトは #）になるよう修正してください。
```

```
他のゲーム固有の表示（評価バーのラベル等）も同様に、切替時に前ゲームの残存表示がないか
一通り確認してください。
```
