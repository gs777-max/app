# ゴルフ試打クラブ＆計測結果 管理表ツール v1.0

ドライバーの試打セッション（ヘッド×シャフト×グリップ×設定）と
弾道計測結果を管理し、総合スコアで自動ランキングする単一ファイルHTMLツール。
元ファイル（ユーザーが 2026-11-23 にアップロードした2026年版）を分析し、
見つかった問題を修正した版。

## 公開URL

https://gs777-max.github.io/app/pre_fitting_result_list/

## v1.0での修正（詳細は ISSUES.md）

- **打者（個人名）欄を追加** — 元ファイルには打者・氏名の欄がどこにも無かった。
  登録フォーム／ランキング／ログ／打者フィルタ／A/B比較／CSV に追加。
  既存49件の打者は推測で入れていない（すべて「未記入」）。
- **編集時のデータ消失バグを修正** — 旧版は編集保存時に打ち出し角・ミート率を
  `null` で上書きして消していた。フォームに両項目を追加し、保存時に保持する。
- **集計表示を自動計算に** — 旧ヘッダーの「全47セッション・463球」は誤り
  （実データは49件、有効46件・453球、日付は2026-09-12を含む）。実データから計算する。
- **JSON読込に検証を追加** — 必須項目・ID重複をチェックし、不正な場合は
  現在のデータを変更しない。
- **CSVを拡充・堅牢化** — 打者・クラブ・打ち出し角・ミート率を追加し、
  カンマ／引用符を含むメモも壊れない引用符エスケープに変更。
- **ラベル明確化** — BS→「BS・初速」、CS→「CS・ヘッドスピード」、
  SS→「サイドスピン (rpm)」。
- **スコアの相対性を注記** — 総合点は現在の有効セッション内での相対順位
  （min-max換算）で、セッションの増減で過去の点数も変わることを明記。
  スコア式自体は v1.0 では変えていない。

## 使い方

1. 公開URLを開く（インストール不要）。
2. 「新規試打を登録」でセッションを追加する。**打者（個人名）** を入れると
   ダッシュボードの「全打者」フィルタで個人別に絞れる。
3. ダッシュボードのスライダーで「飛距離 vs 方向安定性」の配点を変えると
   ランキングがリアルタイムで変わる。
4. 「JSON保存」でバックアップを取る（データはブラウザの localStorage
   にのみ保存され、サーバーには送られない）。

## 注意

- データはブラウザの localStorage にのみ保存される。端末・ブラウザを変えると
  データは引き継がれない。定期的に JSON保存でバックアップすること。
- 旧版（v2キー）の保存データがあるブラウザでは、初回表示時に自動で v3キーへ移行する。
- 総合点は相対評価。マスタ画面の「エース超え合格判定基準」はスコア計算には
  使われていない（ISSUES.md P1-2参照）。
