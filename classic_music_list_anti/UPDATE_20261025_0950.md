## 1. 改修の目的
- **「気軽に音楽を聴くこと」**: モーダルを閉じても途切れず聴けるグローバルプレイヤー化、洗練された下部バー統合。
- **「ピアノ演奏の上達」**: ABリピートによる難所反復練習、Web Audio APIによる本格メトロノーム、IMSLP楽譜検索連携、オリジナル練習プレイリストの構築。

---

## 2. 実装された機能詳細

### 【フェーズ1：通常再生プレイヤーのグローバル化 & 再生コントロール拡張】
1. **通常再生プレイヤーのグローバル化**
   - 従来のモーダル内専用プレイヤーとランダム再生用下部バーを統合。
   - 画面下部にフローティング配置される洗練された **グローバル・プレイヤーバー（`#playerBar`）** を実装。
   - モーダルで楽曲やトラックを選択して再生開始した際、**モーダルを閉じてもバックグラウンドで曲が途切れず再生し続ける** ようUI・オーディオエンジンを設計。
2. **再生コントロールの追加**
   - **10秒巻き戻し / 10秒早送りボタン**:
     - `⏪ 10` および `10 ⏩` ボタンを操作部に追加。
     - 現在再生位置から前後に10秒ジャンプ（範囲外チェック対応）。
   - **再生速度変更セレクトボックス**:
     - `0.5×`, `1.0×（デフォルト）`, `1.5×`, `2.0×`, `3.0×` の5段階セレクター。
     - 速度変更時は `audio.preservesPitch = true`（ベンダープレフィックス対応）を強制し、音程が変わらない高品質再生を実現。ピアノの速いパッセージの確認や耳コピ練習に最適。
   - **1曲ループ再生トグル**:
     - `🔂 1曲ループ` ボタンを配置。
     - ONの時は曲終了時に自動で先頭（またはA点）から再ループ再生。
3. **キーボードショートカット**
   - **Spaceキー**: 再生 / 一時停止のトグル（ブラウザのスクロール動作を抑止）。
   - **左右矢印キー（← / →）**: 10秒巻き戻し / 10秒早送り。
   - ※入力欄（`input`, `textarea`, `select`, `contenteditable`）フォーカス時はショートカットが無効化され、検索や文字入力を阻害しません。
4. **Media Session API 連携**
   - スマホ（iOS Safari / Android Chrome）やPC（macOS / Windows）のOS標準メディアコントロールに対応。
   - 曲名、作曲家名、アルバム名、作曲家の肖像画アートワークを `navigator.mediaSession.metadata` に設定。
   - ロック画面、コントロールセンター、Bluetooth機器からの「再生」「一時停止」「10秒巻き戻し」「10秒早送り」「次へ」「前へ」「シーク」イベントに完全対応。

---

### 【フェーズ2：ピアノ練習向け機能（ABリピート・メトロノーム・楽譜）】
1. **ABリピート（部分ループ）機能**
   - プレイヤーバー内の「🎹 練習ツール」からワンタップで展開。
   - **「📍 A点設定」「📍 B点設定」「✕ クリア」** ボタンを配置。
   - 現在の再生位置を即座にA点・B点として記録し、シークバー上に視覚的な **「A」「B」ピンマーカー** とループ区間ハイライトを表示。
   - 再生時間がB点に達した瞬間、自動的にA点へシークしてスムーズにループ再生を継続。
2. **Web Audio API メトロノーム機能**
   - プレイヤーの音源再生とは完全に独立した `AudioContext` ベースのシンセサイズ・クリック音生成。
   - 1拍目（高音1200Hzベル音アクセント）と通常拍（800Hz木製クリック音）のメリハリあるクリック音。
   - **BPM調整**: 30〜250 BPMスライダー、数値表示、`-5` / `-1` / `+1` / `+5` 微調整ボタン。
   - **拍子選択**: 拍子なし、2拍子（2/4）、3拍子（3/4）、4拍子（4/4）、6拍子（6/8）。
   - **ビートLEDインジケーター**: テンポと拍数に合わせて光るアニメーションドット。
   - **Tap BPM機能**: ボタンをクリック/タップする間隔からリアルタイムでBPMを測定・自動設定。
3. **IMSLP 楽譜検索リンクの追加**
   - 楽曲詳細モーダル内に **「🎼 楽譜を探す（IMSLP 国際楽譜ライブラリー）」** セクションを追加。
   - 検索クエリ「`作曲家名 + 曲名 + IMSLP`」を自動生成し、Google検索の該当IMSLPページ検索結果を `target="_blank" rel="noopener noreferrer"` で開くリンクを設置。

### 【フェーズ3：オリジナルアルバム（プレイリスト）作成機能】
1. **データ管理（`localStorage`）**
   - 従来の単一お気に入り（`favW`）の仕組みを大幅に拡張し、ユーザーが自由な名前で複数のプレイリストを作成・保持できるデータ構造（`opus.playlists`）を構築。
2. **直感的なUIの追加**
   - **ヘッダー「📁 アルバム管理」ボタン**:
     - アルバムの新規作成、一覧表示、名前変更（リネーム）、削除、収録曲リストの展開確認・個別削除モーダルを提供。
   - **楽曲カードの「☆」ボタン拡張**:
     - 各楽曲カードの星ボタンを押すと、登録先アルバムを選択できる **洗練されたドロップダウンポップアップ** が出現。
     - 「★ お気に入り楽曲」および作成済みアルバムのチェックボックス一覧からワンタップで振り分け可能。
     - その場で「＋ 新規アルバム名」を入力して即座に作成＆追加も可能。
3. **アルバム連続再生機能**
   - 作成したアルバムの「▶ 再生」ボタンを押すと、下部プレイヤーバーが「アルバム再生モード」へ移行。
   - 1曲目から自動的にInternet Archiveの音源を検索して連続再生。
   - 曲が終わると自動で次の曲へシーク、下部バーの「⏮ 前へ」「⏭ 次へ」でもアルバム内の曲を自由にスキップ可能。
