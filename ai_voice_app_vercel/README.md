# AIボイス — 日常ではなす相棒 (v3.2 スマホ没入)

Google Gemini Live API（WebSocket 双方向音声ストリーミング）を使った、リアルタイム音声対話Webアプリケーションです。Vercel へのデプロイに最適化されたサーバーレス関数アーキテクチャを採用しています。

デプロイ済みサイト: https://app-aivoiceappvercel.vercel.app/

## 今回の改修内容 (v3.2 スマホ没入、2026-11-19)

「スマホの視認性・操作性・没入性が極めて低い」という評価を受け、モバイルファーストで画面を作り直しました。会話エンジン（v3.1）は無変更で、UI構造の刷新と配線の追加だけを行っています。実機ライブ音声は未検証です。

1. **アプリシェル**: `100dvh` + `viewport-fit=cover` + `env(safe-area-inset-*)` 対応。会話中はパートナー選択を隠してスクロールしない1画面にします。ヘッダーはブランド＋状態＋設定だけにスリム化し、ログ保存は会話記録シート内へ移しました。
2. **ステージヒーロー**: パートナー写真を大きく表示（モバイル縦3:4、デスクトップは最大幅720px内で抑制）し、下部スクリムの上に名前（大）・状態ピル（聞いています／考えています／話しています）・ライブ字幕（AIの最新発話、20px以上・最大2行）を重ねました。聞き取り中はパルスリング、発話中は高さ72pxの波形、考え中はドットアニメーション、呼吸のような緩やかな拡大（1.0→1.015）で存在感を出します。`prefers-reduced-motion` では全アニメーションを停止します。口の簡易表示は振幅連動のまま控えめに残しました。
3. **親指ドック**: 画面下部に固定（safe-area対応）。主ボタンは高さ68px・全幅・文字18px以上。その上にマイクレベルと「応答」遅延チップをモバイルでも表示します（従来のモバイル非表示を廃止）。副操作は円形56pxのアイコン＋ラベル4つ（割り込む／マイク／一時停止／文字）で折り返しません。`touch-action: manipulation` を入れました。
4. **パートナー選択**: 横スナップスクロールの大きなカード（写真大・名前・性格1行・声タグ・選択中バッジ）にしました。準備中の3人（ミサキ／ケンジ／サトコ）はぼかし＋鍵バッジ＋「近日公開」のティーザー表示にし、壊れた無効ボタンに見せません。会話中の切替は既存の再接続ロジックのままです。
5. **ボトムシート化**: 会話記録（つまみ付き・最大70dvh・17pxの吹き出し・自動スクロール・文字入力と診断ログタブを含む）、気分・話し方（感情チップ52px・スライダーのつまみ32px）、設定（APIキー欄は「上級者向け」の折りたたみ内、接続バッジを大きく表示）をすべてボトムシートにしました。既存の `tab-chat` / `tab-diag` の配線は維持しています。
6. **視認性**: 基本文字を17pxにし、状態・字幕・名前を大きく太くしました。写真上は白文字＋影で屋外でも読めるコントラストにしました。モバイルで情報を隠す指定（説明文・遅延の非表示）は廃止しました。
7. **マネタイズ導線（UIのみ・正直に）**: 上部に「無料でお試し中」＋セッション経過時間＋「プランを見る」を置きました。プランシートには Free / Plus の特典比較を表示しますが、決済は未実装なので購入ボタンは「準備中」で無効化し、買えるふりはしません。プレミアムパートナーにはバッジを付け、会話終了時にはセッション要約（時間・やりとり数・平均応答の実測平均）を表示します。
8. **スマホ実用**: WakeLock（会話中は画面を消さない）、触覚フィードバック（開始・終了・割り込みで短く振動）、iOSの入力時ズーム防止（入力欄16px以上）、`apple-mobile-web-app` メタを追加しました。

## 今回の改修内容 (v3.0)

v2.9の速度改善（遅延計測・AudioWorklet・220msターン確定・再生キュー上限）を残したまま、画面を全面リデザインしました。ネオ・サイバーHUDをやめ、日常系のプロ仕様にしています。

1. **デザインシステムの刷新**: 紺黒背景＋シアンネオン、Orbitron/Rajdhaniフォント、走査線・レティクル・グリッドを全廃。白と暖かいグレーを基調に、アクセントは深い緑1色だけにしました。フォントは Zen Kaku Gothic New 1ファミリーに統一。グラデーションやグローは使っていません。
2. **モバイルファーストの1カラム**: 3カラムHUDをやめ、最大幅720pxの1カラムにしました。導線は「1. パートナーを見る → 2. 会話をはじめる → 3. パートナーを選ぶ → 4. 文字で見る」の4ステップです。会話開始ボタンは56pxの大きなボタン1つです。
3. **操作性の改善**: ピンチズームを許可しました（`user-scalable=no` を解除）。タップ領域は44px以上、文字サイズは16px基準です。フォーカス表示とキーボード操作、スクリーンリーダー用のラベル（`aria-label` / `aria-pressed` / `role="log"`）を入れました。`prefers-reduced-motion` にも対応しています。
4. **パートナー表示の改善**: 音声振幅に連動した簡易的な口の動き（音声がないときは動きません）と、話しているときだけの控えめな枠色変化を入れました。スペクトラムは細い単色バーにしました。パートナー名は日常系に見直しました（HOLO-AI → ハル、LUNA → ルナ、REN → レン）。声の割り当て（Aoede / Kore / Fenrir）は変わっていません。
5. **パートナー選択カード**: 写真付きカード式にしました。既存3人に加え、ミサキ（40代・女性）、ケンジ（50代・男性）、サトコ（60代・女性）の3スロットを用意しました（写真準備中につき現在は選択不可）。
6. **気分設定の正直化**: 感情メーターの見せかけ表示をやめ、「気分はあなたの設定です。音声から感情を読み取っているわけではありません」と明記しました。気分の詳細設定は「詳細設定」に折りたたみました。
7. **品質基盤**: SEO meta・OGP・favicon・theme-color を追加しました。Google Fontsの読み込みを Zen Kaku Gothic New 1ファミリーだけに減らしました。バージョン表記を v3.0 に統一しました。

## パートナー写真の差し替え手順（6バリエーション）

現行の写真は、旧デザイン時の静止画JPG 3枚を一時的に使っています（`public/assets/cyber_holo_face.jpg` など。ファイル名は旧名称のままです）。写実系・日常系の新写真が用意できたら、次の手順で差し替えてください。

1. 写真を用意する（写実的・日常の服装・自然な背景。SF・サイバー要素なし）。推奨：正方形、1024×1024以上。
2. WebPに変換して軽量化する（例：`cwebp -q 80 入力.jpg -o 出力.webp`）。ファイルサイズは1枚200KB以下を目安にする。
3. `public/assets/` に置く。ファイル名の例：`haru.jpg` → `haru.webp`、`luna.webp`、`ren.webp`、`misaki.webp`、`kenji.webp`、`satoko.webp`。
4. `public/index.html` の `characters`（`holo` / `luna` / `ren`）の `image` を新しいパスに変える。ミサキ・ケンジ・サトコは現在HTMLの「写真準備中」カードなので、写真が用意できたらそのカードを有効な選択ボタンに変え、対応する `characters` エントリーと声を追加する。
5. 差し替え後は `node --check` でJS構文を確認し、ブラウザで表示を確認する。

## 今回の改修内容 (v3.1 会話流暢化、2026-11-19)

会話が成り立たない原因だった setup／ターン判定／VAD／割り込み／再接続を直しました。実機ライブ音声は未検証です。

1. **setupを仕様通りに**: `responseModalities` を `['AUDIO']` のみにし、`inputAudioTranscription` / `outputAudioTranscription`（言語 `ja-JP`）を setup に入れました。VAD感度を `START_SENSITIVITY_HIGH` / `END_SENSITIVITY_HIGH` に直しました。setupの再送はやめ、感情・強さの変更は `clientContent` でのシステム指示更新、パートナー（声）の変更は再接続で行います。
2. **ターン判定をゆるめた**: クライアント無音 220ms → 600ms、サーバー `silenceDurationMs` 200ms → 500ms。言いよどみ・間で切れにくくしました。
3. **VADのしきい値暴走を防止**: `noiseFloor` のEMA更新は無音フレームのときだけにしました。既定の割り込み感度をコードと画面で `normal` に統一しました。
4. **割り込み**: `interruptAudio()` でローカル停止に加え、サーバーへ生成中断（`realtimeInput.activityStart`）を送ります。バージイン後、ユーザー発話が終わるまでAIの新規音声チャンクを再生キューに入れません。
5. **切断・再接続**: `data.error` / `goAway` / `sessionResumptionUpdate` を画面に表示し、setupに `sessionResumption` を入れました。1006等は指数バックオフで最大3回自動再接続、1007（setup不正）は設定エラーとして再接続しません。開始ボタンの連打による二重接続を防ぎ、キー取得のfetchに5秒タイムアウトを入れました。

## 既知の制限（次フェーズ）

- **実機未検証**: Gemini の生キーなしではライブ音声の実機テストはできていません。ブラウザでの動作確認が必要です。
- **APIキーの秘匿化は未完了**: `/api/key` は認証なしで生のGeminiキーを返します（CORSは自サイトとlocalhostに限定済みですが、サイト訪問者は誰でもキーを読めます）。次フェーズでサーバー側プロキシ化（キーをブラウザに渡さない設計）、アカウント・無料枠・利用制限・Stripe決済・利用規約が必須です。
- **パートナー写真は旧画像のまま**: 上記の差し替え手順の通り、写実系の新写真への差し替えはまだです。
- **決済は未実装**: v3.2でプラン表示（Free / Plus）のUIだけを置きました。購入ボタンは「準備中」で無効化してあり、実際に課金はできません。アカウント・無料枠・利用制限・Stripe決済・利用規約は次フェーズです。
- **フォールバック経路は非ストリーミングのまま**: Live API切断時は数秒遅くなることがあります。

## Vercel へのデプロイ手順

1. **GitHub リポジトリへプッシュ**:
   `ai_voice_app_vercel` 以下のコードを GitHub にプッシュします。

2. **Vercel ダッシュボードでインポート**:
   - [Vercel Dashboard](https://vercel.com/) にログインし、「Add New Project」からリポジトリを選択します。
   - Root Directory を `ai_voice_app_vercel` に指定します。

3. **環境変数 (Environment Variables) の登録**:
   Vercel のプロジェクト設定画面で以下の環境変数のいずれかを登録します：
   - **Key**: `GEMINI_LIVE_API_KEY`（または `GEMINI_API_KEY`）
   - **Value**: Google AI Studio で取得した Gemini API キー

4. **デプロイ完了**:
   デプロイ後、公開URLにアクセスすると自動的に Vercel サーバーレス関数からキーがロードされ、すぐに音声対話が可能です！

## ローカル実行手順

```bash
# ai_voice_app_vercel ディレクトリで実行
python api/server.py 8080
```
ブラウザで `http://localhost:8080/` を開き、マイクを許可して「会話をはじめる」を押してください。
