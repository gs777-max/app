スキル: 流体すり抜け・紙一重 / 残像フェイント・二段加速 / 鞄結界・ボックスアウト / 心眼・足首ロックオン（ホイールで選んで Enter）
着席中: 寄りかかりは ←/→ で肩すかしパリィ、眠気は Enter 連打で覚醒。お年寄りには決定キーで席を譲ります。着席は座席に近づくと自動です。降車は、ドアが開いている時にドアへ向かって歩く（↑）とできます。
【スマホ】左側スティックで移動 / 右側ドラッグで視点 / 画面のボタン（決定・スキル・避ける）で操作します。
